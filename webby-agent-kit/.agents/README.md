# Webby Agent Kit

This directory contains local instructions for AI-assisted development on Webby.

Use these files by telling your coding agent:

```text
Read AGENTS.md, .agents/context-map.md, and .agents/workflow.md first.
Use the relevant role and skill file for the task.
```

Recommended roles:

```text
.agents/agents/architect.md
.agents/agents/parser-engineer.md
.agents/agents/layout-engineer.md
.agents/agents/renderer-engineer.md
.agents/agents/test-engineer.md
.agents/agents/reviewer.md
```

Recommended skills:

```text
.agents/skills/implement-feature.md
.agents/skills/debug-failure.md
.agents/skills/add-parser-rule.md
.agents/skills/add-layout-rule.md
```

Do not treat agents as magic. They are checklists for keeping work scoped and sane.
