# Review Quality Skill

Use this after a milestone implementation.

## Review targets

- Architecture boundaries.
- Error handling.
- Test quality.
- Hardcoded behavior.
- Parser correctness.
- Layout determinism.
- Renderer separation.
- CLI validation usefulness.
- Documentation drift.

## Output

Return:

1. Blocking issues.
2. Important non-blocking issues.
3. Suggested refactors.
4. Missing tests.
5. Whether the milestone definition of done is actually satisfied.
